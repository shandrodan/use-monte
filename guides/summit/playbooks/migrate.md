# Migrate

For an app that has a design system installed.

1. **Mode.** Full mode only when the ask names the migration or the person replied `Go, <budget>`. Every other ask runs audit mode.
2. **Readiness.** Check that quarry's five readiness audits hold. If one is open, stop here and list its rows. Why: a gap found after screens consume the system costs a sweep across every screen, and one found before costs a row.
3. **Run traverse** through its steps. Audit mode writes only under `.design-system/`, commits nothing and ends at the plan and the offer.
4. **Brief** every worker with its MAY EDIT list and the numbers of the traverse lessons that apply to its surface.
5. **Judge** each return from `git diff` and its verdict file, never from its message. A verdict counts only when it comes from an agent that did not write the code.
6. **Close.** Run traverse's correction pass and the comment review, then inventory again with `legacy.mjs --inventory`.
7. **Report** the unanswered defaults first, then counts from commands, then one ranked table of what was found and not fixed.

Done when `legacy.mjs --zero` exits 0 at the final commit, every surface is `verified` at that commit, and the correction pass has run. Audit mode is done at step 3.
